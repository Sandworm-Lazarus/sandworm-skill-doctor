# Security scope

Skill Doctor is an offline-oriented review aid for user-selected text files. It does not certify skills or authorize their execution. See [the threat model](docs/THREAT_MODEL.md).

For a reproducible bug, provide synthetic files and minimal steps. Do not post real secrets or private skill packages in public issues. Run the test and fixture suites before proposing changes to path handling, limits, parsing, export gates, or hashing.
